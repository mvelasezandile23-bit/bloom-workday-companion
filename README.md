AI Workplace Productivity Assistant
A modern, responsive workplace productivity application designed to help professionals organise tasks, create professional emails, and get assistance with everyday workplace questions.
Features
1. Smart Email Generator
Generate professional emails from user-provided instructions.
Choose between three tones:
Formal
Friendly
Persuasive
Review, edit, and copy generated email content.
2. AI Task Planner
Create daily or weekly schedules from a list of tasks.
Organise tasks by urgency and importance.
Suggest priorities and deadlines to support better time management.
3. AI Workplace Chatbot
Interactive workplace assistant interface.
Responds to workplace-related prompts.
Helps with communication, organisation, and general productivity questions.
Design

Pink and white colour palette.

Responsive desktop and mobile layouts.
Input and output sections.
Editable and copyable responses.

AI and Backend Limitations
This project is designed as a frontend-only application. It does not require a backend, database, user authentication, or external AI API.
AI-style outputs are produced using frontend logic. Therefore, responses are not generated by a live AI model and may be less flexible or accurate than responses from a connected AI service.
A real AI integration can be added in a future version if a suitable API and secure backend are available. API keys should not be placed directly in frontend code.
Responsible AI
AI-generated content should be reviewed before it is used or shared. Users are responsible for checking the accuracy, tone, and suitability of generated emails, schedules, and chatbot responses.
Do not enter confidential company information, passwords, or sensitive personal data.
