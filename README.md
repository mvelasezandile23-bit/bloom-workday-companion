# Bloom Workday Companion

Build a modern, responsive web application called AI Workplace Productivity Assistant.



Create a professional SaaS dashboard inspired by Seas, using a clean pink and white colour scheme, soft pink accents, rounded cards, and a modern layout.



Main features:

1. Smart Email Generator: Generate original, context-aware professional emails from user instructions. Include Formal, Friendly, and Persuasive tones.

2. AI Task Planner: Generate daily and weekly schedules from user tasks. Prioritise tasks based on urgency and importance, with suggested deadlines.

3. AI Workplace Chatbot: Create an interactive assistant that responds intelligently and specifically to workplace-related questions and user prompts.



Design and functionality:

- Dashboard with sidebar navigation.

- Responsive desktop and mobile layouts.

- Separate input and AI-generated output sections.

- Editable and copyable AI-generated responses.

- Interactive buttons, navigation and task cards.

- Professional welcome dashboard.

- Responsible AI disclaimer.



Important technical requirements:



- No backend, database, authentication or external API.

- Use frontend-only functionality and browser local storage where needed.

- Implement AI-style responses using contextual, dynamic frontend logic rather than repetitive generic placeholder text.

- Keep all features functional without paid services.

- Use React and Tailwind CSS.



Make the application visually impressive, easy to navigate, professional and fully responsive. Prioritise working features over unnecessary animations.
